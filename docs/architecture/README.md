# Architecture technique — AZURE SECURE PME

## 1. Présentation

Ce document décrit l'architecture Cloud cible du projet AZURE SECURE PME.

## 2. Objectif

Concevoir une infrastructure Cloud adaptée à une PME, en privilégiant la sécurité, la gouvernance et la maîtrise des coûts.

## 3. Architecture envisagée

- Microsoft Azure : environnement Cloud.
- Azure Static Web Apps : hébergement du portail de démonstration.
- Microsoft Entra ID : gestion des identités.
- Azure RBAC : gestion des autorisations.
- Azure Activity Log : traçabilité des opérations.
- Azure Policy : gouvernance des ressources.
- Azure Cost Management : surveillance des dépenses.
- GitHub : gestion du code source et documentation.

## 4. Principes de sécurité

- Moindre privilège.
- Contrôle des accès.
- Traçabilité des opérations.
- Gouvernance des ressources.
- Surveillance des coûts.

## 5. État du déploiement

Cette architecture est une cible de conception. Chaque composant sera étudié, déployé si nécessaire et testé progressivement.

Les résultats réels seront consignés dans cette documentation.
